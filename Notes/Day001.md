# Day 1 (String and Variables)

### String

```
# print hello world
print("Hello world!")

# use \n to go tothe next line
print("Hello world!\nHello world!\nHello world!")

# use concatination to combine words
print("Hello" + " " + "Angela")
```

### Variable

- variable name can't have space, can't start with numbers, can only use `-` or `_` as symbol

```
# Use variable to capture input and utilize it
name = input("What is your name?")
print("Hello " + name)

# Check the length of the user input
name = input("What is your name?")
num_of_letters = len(name)
print(num_of_letters)
# or ...
name = input("What is your name?")
print(len(name))
# or ...
```
