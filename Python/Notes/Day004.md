### Challenge

**Rock Paper Scissors**

```
import random

rock = '''
    _______
---'   ____)
      (_____)
      (_____)
      (____)
---.__(___)
'''

paper = '''
    _______
---'   ____)____
          ______)
          _______)
         _______)
---.__________)
'''

scissors = '''
    _______
---'   ____)____
          ______)
       __________)
      (____)
---.__(___)
'''
game_images = [rock, paper, scissors]
user_choice = int(input("What do you choose? Type 0 for Rock, 1 for Paper, or 2 for Scissors.\n"))
comp_choice = random.randint(0,2)

print(f"{game_images[comp_choice]}\n")
print(f"Computer choose:{game_images[user_choice]}\n")

if user_choice > comp_choice:
    print("You win!")
elif user_choice == comp_choice:
    print("It's a draw!")
elif user_choice < comp_choice:
    print("You lose!")
else:
    print(f"{user_choice} is not a valid option.")

```
