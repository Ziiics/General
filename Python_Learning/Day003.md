### Control Flor If/Else

- Indentation is very important and you can get an error if the indentation is wrong.
-

```
# Comparator Operators
  > Greater than
  < Less than
  >= Greater than or equal to
  <= Less than or equal to
  == Equal to
  != Not equal to

# Conditional statement (if/else)
if condition:
  do this
else:
  do this instead

# Nested If/Else (if/elif/else)
if condition1:
  do A
elif condition2:
  do B
else:
  do this

# Logical Operators
A and B #Both conditions need to be true
C or D #Only one condition needs to be true
not E #The condition must be false

```

**Multiple If Statement**

