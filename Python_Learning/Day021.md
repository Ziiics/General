### Inheritance and Slicing

- **Inheritance** is when you have a certain value of the class, but with additional things
- **Slicing** getting a certain part of the list

```
# Creating/defining Inheritance
class Fish(Animal):
    def __init__ (self):
        super().__init__()

# Slicing a list - also works with tuple, the same exact way and symbol
piano_kekys = ["a","b","c","d","e","f","g"]
print(piano_keys[2:5])    # output [c,d,e]
print(piano_keys[2:5:2])  # the third number sets the increment, output [c,e]
print(piano_keys[::2])    # the third number sets the increment, output [a,c,e,g]
print(piano_keys[::-1])   # manipulate list to reverse the order, output [ag,f,e,d,c,b,a]

```

### Example of Fish class inhereting from Animal

```
class Animal:

    def __init(self):
        self.num_eyes = 2

    def breathe(self):
        print("Inhale, exhale")


class Fish(Animal):

    def __init__(self):
        super().__init__()

    def swim(self):
        print("Moving in the water")

    # doing something extra from the super class
    def breathe(self):
        super().breathe()
        print("But under water")

# Usage

nemo = Fish()
nemo.breathe()
nemo.swim()
```
