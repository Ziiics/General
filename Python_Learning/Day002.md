## Day 2 (Data Types, Numbers, Operations, Type Conversion, f-Strings)

### Primitive Data Types

- String can be taken per each characters as long as it is in a double quote.

```
# subscripting
print("Hello"[-2])

# String
print("123" + "456")

# integer = whole number
print(123+456)

# large integer
print(123_456_789)

# Float = Floating Point Number
print(3.14159)

# Boolean
print(True)
print(False)
```

### Number Manipulation

```
# Two ways to output int from float
print(int(3.7))   // output 3 (only removing int)
print(round(3.7)) // otuput 4 (based on regular math)

# User these to manipulate number based on its previous value
+=
-=
*=
/=

# f-String is used to add int value to a string
age = 26
print(f"I am {age} years old")  // important to add f in front of the string
```

**Tip Calculator**

```
print("Welcome to the tip calculator!")
bill = float(input("What was the total bill? $"))
tip = int(input("What percentage tip would you like to give? 10 12 15 "))
people = int(input("How many people to split the bill? "))

tipTotal = bill * tip/100
cost = (bill + tipTotal) / people
cost_2decimal = round(cost, 2)  # rounding to 2 decimal too

print(f"The bill is {bill}")
print(f"The tip is {tipTotal}")
print(f"Each person should pay: ${"%.2f" % cost}")  # print only 2 decimal
print(f"Each person should pay: ${cost:.2f}")       # print only 2 decimal
print(f"Each person should pay ${cost_2decimal}")
```
