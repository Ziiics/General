# Scope & Number Guessing Game

### Scope - Local vs Global Scope

- local scope: declared inside functions, only seen by other code within the same block code. If/else doesn't count as local scope, only if object is created inside functions
- global scope: variables or functions declared at the top level and accessible anywhere in the code

```
# to update global variable when caling it right away, this is the way
sample = 0
def update_sample():
    global sample
    sample += 1

# but the way is not safe, better to
sample = 0
def update_sample(the_sample):
    the_sample += 1
    return the_sample
update_sample(sample)
```

#### isPrime

```
def is_prime(num):
    i = 1
    while i < num-1:
        i += 1
        if num % i == 0:
            return False
    return True

print(is_prime(73))
```

#### Number Guessing Game

```
import random

print("Welcome to the Number Guessing Game!")
print("I'm thinking of a number between 1 and 100.")

difficulty = input("Choose a difficulty. Type 'easy' or 'hard': ")
chances = 0
if difficulty == "easy":
    chances = 10
elif difficulty == "hard":
    chances = 5

selected_number = random.randint(1, 100)
print(selected_number)

while chances > 0:
    print(f"You have {chances} attempts remaining to guess the number.")
    guess = int(input("Make a guess: "))
    if guess != selected_number:
        if guess > selected_number:
            print(f"Your guess is too high.")
        elif guess < selected_number:
            print(f"Your guess is too low.")
        chances -= 1
    else:
        print(f"You got it! The answer was {selected_number}.")
        break

print("You've run out of guesses. Refresh the page to run again.")
```
