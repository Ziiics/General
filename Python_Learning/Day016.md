# Day 16 - OOP (Object Oriented Programming)

### Descriptions

We have been doing **procedural programming** (we setup multiple procedures and procedures to process the value). But to create a bigger projects, it's important to modularize and split it so it's maanagable.
**This is Object Oriented Programming**.

It is called OOP because it mimics real life when each module is an object in the world where each is assigned a designated task.

OOP consist of,

- class: the blueprint that can be used to make another object. It will always start with capital.
- object: the individual result of the blueprint.
- attributes: the things that the object have.
- methods: what an object can do, modeled by function.

```
// creating an object
car = CarBlueprint()
  // CarBlueprint() is the class
  // car is the object

// to call the object's attributes
car.speed = value

// to call the function
car.move()
car.stop()
```

### Packages

- **Package** - structural container or namespace that groups related code files and classes together
- **Object-Oriented Programming (OOP)** - a programming paradigm based on bundling data and behavior into individual objects and classes.

### Coffee Machine Relying on OOP

```
from menu import Menu
from coffee_maker import CoffeeMaker
from money_machine import MoneyMachine

money_machine = MoneyMachine()
coffee_maker = CoffeeMaker()
menu = Menu()

is_on = True

while is_on:
    options = menu.get_items()
    choice = input(f"What would you like? ({options}) ")
    if choice == "off":
        is_on = False
    elif choice == "report":
        coffee_maker.report()
        money_machine.report()
    else:
        drink = menu.find_drink(choice)
        if coffee_maker.is_resource_sufficient(drink) and money_machine.make_payment(drink.cost):
            coffee_maker.make_coffee(drink)
```
